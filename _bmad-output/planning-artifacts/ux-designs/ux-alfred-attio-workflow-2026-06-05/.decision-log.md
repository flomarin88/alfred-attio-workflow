# UX Decision Log — Alfred Workflow for Attio CRM

Canonical memory and audit trail. Every UX decision, override, and creative-tool outcome is recorded here.

---

## 2026-06-05

- **Intent:** Create UX (both spines from scratch).
- **Stakes calibration:** Public / community (inherited from PRD decision log — public OSS workflow distributed via GitHub Releases). DESIGN.md and EXPERIENCE.md run at full rigor.
- **Form-factor:** Alfred 5 on macOS — a constrained surface. Most "visual" UX flows through Alfred's own theming (icons + title + subtitle in ScriptFilter items, mods, Quick Look pane). The workflow only owns full visual control inside Quick Look HTML; everywhere else it composes within Alfred's chrome.
- **Sources inherited from PRD:** UJ-1 (morning todo), UJ-2 (universal search), UJ-3 (first-time install), UJ-4 (deal stage update). FR-013 (per-object context line) and addendum §E (per-object Quick Look + drill-down field maps) define the IA surface.

- **Brand direction (Florian's brain dump):**

  - **Mood:** editorial-cold, à la Attio. Calme productif, simplicité.
  - **Brand reference:** Attio itself. The workflow should feel like a first-party extension of Attio, not a third-party tool. Visual language inherited verbatim where possible — palette, typography, spacing, iconography.
  - **Iconography:** Attio's own icon set (or as close as we can get without licensed assets). Object icons (person / company / deal / task) must read as Attio's, not generic.
  - **Light + dark:** both modes shipped from V1. Attio supports both; the workflow follows.
  - **Emotional stakes:** calm productivity, simplicity. Not energetic, not urgent, not playful. The morning-todo user reads the Quick Look fiche with calm focus, not "fix these deals now".
  - **Why:** Florian's call. Attio's audience is already on Attio's visual language; copying that language collapses the cognitive switch cost — exactly what the PRD thesis ("1–3 keystrokes") wants. Inventing a new visual identity would create friction at zero strategic upside.
  - **How to apply:** DESIGN.md tokens are derived from Attio's public surfaces (app.attio.com, marketing site, public Figma if any). Where Attio uses licensed type (e.g. a custom display face), the workflow falls back to system-ui or the nearest open-source equivalent — flagged inline. Quick Look HTML is the main canvas where we can apply these tokens faithfully; Alfred list items inherit Alfred's theme and can only carry icon + microcopy.

- **2026-06-05 (validation update kickoff) — 3 reviewers ran (rubric / adversarial / a11y) returning 6 critical + 14 high + 15 medium + 12 low findings.** Approach: apply criticals + load-bearing highs as autofix, document remaining as Known Limitations, defer cosmetic items.
- **Trademark / non-affiliation — reframe applied.** Brand directive rewritten from "mirror Attio" to "register-compatible with Attio without claiming origin." Non-affiliation disclaimer added to first-run notification and `attio:diag` row 0; README plan must include the non-affiliation section. Lucide (ISC) committed for all object icons in V1 with explicit `person → user`, `company → building-2`, `deal → handshake`, `task → circle-check` mapping — no tracing from Attio assets. Inter bundled with the `.alfredworkflow` as WOFF2 (SIL OFL allows redistribution); never relied on as a system font.
- **1-3 keystrokes constraint reframed as "deliberate keystrokes".** Excludes ⌥space, arrow navigation, query typing, backspace return, escape close. F-G scalar field edit (drill-down → edit row → option) lands at exactly 3 — the ceiling. Anything more is V2.
- **Persona dropped to "the user" across all 4 KFs** (consistent with PRD §3 decision). Removed Florence introductions, biographical detail, and gendered pronouns. KFs read as keystroke flows with role-neutral framing.
- **A11y contrast fixes.** Light mode: `ink-secondary` `#5e6066` → `#54565b` (5.9:1), `ink-tertiary` `#9b9da3` → `#6e7077` (4.6:1, passes AA-body), `outline` `#d4d6d9` → `#9ea0a6` (3.05:1, passes 3:1 UI). Dark mode: `ink-secondary` darkened to `#b7b9be`, `ink-tertiary` to `#9b9da3` (4.71:1 against `#101113`), `outline` to `#5e6066` (3:1 against surface-raised).
- **FR microcopy improved.** Fixed English-shaped FR strings ("re-paste in config sheet" → "mettre à jour dans les préférences Alfred"; "Token changé" → "Token mis à jour"; removed redundant "Attio" in "Token API non configuré"). Per-object empty-search strings replace the genderless `Aucun·e {object}` interpolation with native FR plurals per object type. Date format placeholder shifted to native FR convention `AAAA-MM-JJ`.
- **`attio:diag` token-hash leak removed.** Row 3 now shows `Token: configured` or `Token: missing` with no hash, no prefix, no length. Added a disclaimer preface row 0 ("Unofficial workflow for Attio — share for support · does not contain token or record content"). Row 2 identity opt-out via `DIAG_INCLUDE_IDENTITY=false`. Row 5 endpoint patterns strip record IDs.
- **Known Limitations section added.** Documents the single-level drill-down constraint, Quick Look mouse-only copy, onboarding cliff, subtitle truncation priority, no-undo on mark-complete, todo-vs-task-search mapping divergence, no-cancel during edit, 9-result cap. Each is design-intent, not a bug, surfaced explicitly so support threads don't re-litigate them.
- **`OVERDUE` heading localized.** EN `OVERDUE` / FR `EN RETARD`. The earlier `RETARD` alone was a French loan in an EN context.
- **Quick Look reframed as "non-mutating" rather than "read-only".** Reading and copying with mouse is supported; mutating actions require close-then-act flow because Alfred's Quick Look does not natively pass mods.
- **Why all of this.** Adversarial review flagged trademark exposure as the single highest-stakes risk; a11y review flagged 2 critical contrast failures; KF-4 keystroke count was sold but not budgeted. These are decision-readiness gates for a public OSS release, not cosmetic. The remaining mediums/lows are tracked in `review-*.md` files for future revisions; they don't block V1.0.0 shipping.

Reconciliation against PRD applied (7 reconciliation gaps closed: per-type input UX, lifecycle attribute, FR-030 microcopy, NFR-007 pre-flight block, list-of-records grouping, 1-3 keystrokes constraint, edge-case rot covered). Reviewer pass executed (3 reviewers, findings consolidated and applied). Polish skipped — the editorial polish would not change grade and the spines are tight enough for downstream consumption. External handoffs empty per customize.toml. Common next: `bmad-create-architecture` to design the technical solution, then `bmad-create-epics-and-stories` to break work into stories.
